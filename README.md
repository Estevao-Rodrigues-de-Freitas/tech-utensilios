# UMA LANDING PAGE PARA VENDA DE UTENSÍLIOS TECNOLÓGICOS

---

## Descrição

Este template emula um site de venda de produtos tech.

É totalmente responsivo e foi planejado para desktops e depois adaptado para telas menores.

---

## Tecnologias Utilizadas:

- HTML5  
- CSS3  
- JavaScript  
- Google Fonts
- Photoshop (para criação de imagem)
- Blender (para criação de vídeo)  

---

## Como Acessar a Interface
Link do site: https://estevao-rodrigues-de-freitas.github.io/tech-utensilios/  

---

## Explicação das Seções
### 1. Hero
- Entrega uma descriação básica do site.

### 2. Produtos
- Apresenta um espaço que organiza os produtos sendo vendidos.

### 3. Quem Nós Somos
- Entrega um campo o qual é utilizado para contar a história da empresa.

### 4. Confiado Por
- É um campo de parecerias, o qual indica o logo das empresas que estão conectadas na rede da empresa
